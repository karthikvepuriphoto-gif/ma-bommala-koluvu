# Telugu strings to check

Karthik, the app can show English or Telugu. The Telugu below is simple on purpose. Please correct anything that sounds odd. The word we were least sure about is **మెట్టు** for a koluvu step. Many families say **పడి** instead. If పడి is the word your parents use, it should replace మెట్టు everywhere.

| English | Telugu in the app | Why it might need a change |
| --- | --- | --- |
| Which step? | ఏ మెట్టు? | పడి may be the familiar word for a koluvu tier. |
| Step 1 | 1వ మెట్టు | The same మెట్టు / పడి question. The వ ending is used for every number (1వ, 2వ, 3వ). |
| Browse by step | మెట్ల వారీగా చూడండి | Depends on మెట్టు. |
| Set or theme | సెట్టు | “Set” is left as the common loan word. |
| Wedding set | పెళ్లి సెట్టు | Fine if సెట్టు is acceptable. |
| Village set | ఊరి సెట్టు | Could be గ్రామపు సెట్టు if that sounds better. |
| Who gave it | ఎవరు ఇచ్చారు | Straightforward. |
| When | ఎప్పుడు | Very short. The English also says “When”. |
| Year it joined | ఏ సంవత్సరంలో వచ్చింది | Could be చేరిన సంవత్సరం. |
| Material | దేనితో చేశారు | Literally “what is it made of”. |
| Needs repair | బాగు చేయాలి | Clear, but not a single noun for “condition”. |

| The end | ఇంతే | Used as the suggested closing card. |
| Waiting to upload | అప్‌లోడ్ కావడానికి వేచి ఉంది | అప్‌లోడ్ is a loan word. |
